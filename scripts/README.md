# Scripts

Utility scripts used throughout the project.

- `preprocess_audio.py` – convert any audio file to a 16 kHz mono WAV file.
  This is a lightweight example; the full ingestion pipeline lives under
  `runyoro_speech_ai/`.
- `train_text.py` – simple language model fine-tuning example.
- `chat.py` – interact with a trained model.

Additional training utilities will be added over time.
